# API5 – Broken Function Level Authorization (BFLA)

This folder contains a practical assessment of a **Broken Function Level Authorization (BFLA)** vulnerability identified in the **CRAPI** laboratory environment.

## Vulnerability Summary

* **Category:** OWASP API5:2023 – Broken Function Level Authorization
* **Technique:** HTTP method tampering and predictable REST API path manipulation
* **Impact:** Unauthorized access to admin-only functionality leading to deletion of protected video resources

## Included Files

* `report.md` – Detailed professional vulnerability report
* `burp-request-response.txt` – Captured HTTP requests and responses
* `screenshots/` – Supporting screenshots and proof-of-concept evidence

The assessment was performed in an **authorized CRAPI laboratory environment** for educational and defensive security learning purposes.
